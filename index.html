Writes your current plan back to plan.json in your repo, so every device — and Claude — sees it. The token stays in this browser and is never part of the page.

Plan source

Point this at a raw JSON URL — a GitHub Gist raw link works well — and the page pulls the itinerary from there on every load, on every device. Then updating the plan is one edit to a small file instead of re-uploading this whole page.

Edits save automatically, per version, to whichever browser you are using — they are not synced between devices and they are not published with the page. Move them with Download backup and Restore from file. Do that before any big rewrite, and before you leave for a trip you will be following on your phone.
